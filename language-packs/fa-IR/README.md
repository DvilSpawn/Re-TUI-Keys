# Persian language pack (`fa-IR`)

Data-only Re:TUI Keys language pack using the Iranian standard Persian key
arrangement, Persian digits, RTL suggestions, Persian/Arabic character
normalization, and zero-width non-joiner support.

The word frequencies are derived from the historical AOSP LatinIME
`dictionaries/fa_wordlist.xml` (version 12), licensed under Apache-2.0. The
release archive includes the corresponding notice.
