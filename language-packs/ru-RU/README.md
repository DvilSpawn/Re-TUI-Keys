# Russian language pack (`ru-RU`)

Data-only Re:TUI Keys language pack for Russian, using an ortholinear
`"rowStyle": "grid"` layout: three rows of twelve identically sized keys, with
BACKSPACE in the first column of the bottom row and SHIFT in the special key
row. Split keyboard turns it into two banks of six, matching a reviung41 or
corne.

Key positions mirror the `lt-LT` pack. All 33 Russian letters are on the board;
the two positions that hold letters Lithuanian has but Russian does not repeat
`щ` and `ю`.

The word frequencies are derived from the AOSP LatinIME
`dictionaries/ru_wordlist.combined.gz` (version 54), licensed under Apache-2.0.
Entries marked `possibly_offensive` are excluded. The release archive includes
the corresponding notice.
