# Lithuanian language pack (`lt-LT`)

Data-only Re:TUI Keys language pack for Lithuanian, using an ortholinear
`"rowStyle": "grid"` layout: three rows of twelve identically sized keys, with
BACKSPACE in the first column of the bottom row and SHIFT in the special key
row. Split keyboard turns it into two banks of six, matching a reviung41 or
corne.

The three rows carry the full 32-letter Lithuanian alphabet plus `q`, `w` and
`x`, so the key positions line up with the physical board.

The word frequencies are derived from the AOSP LatinIME
`dictionaries/lt_wordlist.combined.gz` (version 44), licensed under Apache-2.0.
The release archive includes the corresponding notice.
